
1. Describe the path an HTTP Request takes from a browser to your GitHub Pages site.

When a user types any website's URL into a browser, the browser sends an HTTP request through the Internet to GitHub’s servers. GitHub Pages hosts the static HTML and CSS files. The server responds by sending the HTML file back to the browser. The browser then reads the HTML structure and applies the CSS styling to render the webpage on the screen.

2. Explain how a Docker Container differs from the environment provided by GitHub Pages.


A Docker container provides an isolated environment where developers control the operating system, installed dependencies, and runtime configuration. It allows applications to run consistently across different machines.

GitHub Pages, on the other hand, is a managed static hosting service. It hosts static files like HTML and CSS, and GitHub handles the server setup automatically. Developers can not control the underlying environment.
